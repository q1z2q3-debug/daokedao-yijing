上 经｜蛊

润泽说易

风钻进山底下，出不来了——不通风的地方，最先烂的是里面

蛊卦

一、经文底本

卦辞

蛊。元亨。利涉大川。先甲三日，后甲三日。

六爻

初六：干父之蛊，有子，考无咎，厉终吉。

九二：干母之蛊，不可贞。

九三：干父之蛊，小有悔，无大咎。

六四：裕父之蛊，往见吝。

六五：干父之蛊，用誉。

上九：不事王侯，高尚其事。

《彖》

蛊，刚上而柔下，巽而止，蛊。蛊，元亨，而天下治也。利涉大川，往有事也。先甲三日，后甲三日，终则有始，天行也。

《象》

山下有风，蛊；君子以振民育德。

《序卦》

以喜随人者必有事，故受之以蛊。蛊者，事也。有事而后可大，故受之以临。临者，大也。

二、时代社会背景

巽下艮上：山下有风。

风在山下，闭塞不散，腐气郁积、虫蠹内生，是蛊之本象。

「蛊」本义不是单纯的邪恶巫术，核心是积久而成的蠹坏、沉弊。

众人因悦而相随、因循日久，制度、家道、邦国之中慢慢生出看不见的弊病，积滞腐化，这就是蛊。

随，是大家同心顺随，气氛和悦；但一味顺着旧有的格局、旧的习惯走，不加检省，和悦之下，弊病悄悄滋生。

所以《序卦》说「以喜随人者必有事」——「事」就是蛊，是要去整治、革新的积弊。

商周时代，蛊同时关联两层：一是器物、家室、邦国积弊蠹坏；二是蛊毒，象征看不见、慢慢侵蚀根基的隐患。

老庄看待蛊弊：老子「敝则新」，腐坏本身即是更新的契机；但不可强行猛改，要循节律。

庄子则区分两种「治蛊」：世人疲弊奔波去纠治世事之蛊；至人不陷于这种纠治的循环，不卷入王侯事务，守自身本真。

随是顺悦依从；蛊，是顺随之流弊，是治弊、起新的功课。

三、关键字造字溯源

1. 蛊

《说文》：「蛊，腹中虫也。《春秋传》曰：皿虫为蛊，晦淫之所生也。」

这里有两个源头，须分清：

  • 《说文》的本训是「腹中虫」——人体内部的寄生虫。
  • 「皿虫为蛊」是引《春秋传》（《左传·昭公元年》医和之论）——器皿久积而生虫。

两说都指向同一结构：病在里面，看不见，慢慢腐蚀。

——由「腹中虫」到「家国之弊」，是同一个比喻： 身体里的虫你摸不着，它只是让你一天天虚下去；邦国家道里的弊你也摸不着，它只是让局面一天天坏下去。

投来稿取「器皿密闭生虫」，属《左传》一路；本卷并存《说文》本训「腹中虫」，两源并不矛盾，反而把这个字的分量说足了。

2. 干

此处训「正」（匡正、整治）。

（「干」的本义是「犯」（《说文》「干，犯也」），此处「正」义为引申。且「干」与「裕」在卦中正反成对：一为整治，一为姑息。）

3. 考

亡父、先祖。

4. 裕

宽纵、姑息。「裕蛊」，对积弊宽缓包容、放任不纠——姑息养患。

5. 先甲三日，后甲三日

「甲」为天干之始，代表一个周期的开端。

天干之序：……辛、壬、癸、甲、乙、丙、丁……

  • 「先甲三日」：甲前的辛、壬、癸——一个周期的末端。 用来预察隐患、筹谋革新。
  • 「后甲三日」：甲后的乙、丙、丁——新周期的开头。 用来推行新制、护持新局。

《彖》说「终则有始，天行也」——「先甲」是终，「后甲」是始。 治蛊的全部技术，就在这「终」与「始」之间的六天上。

6. 巽而止

下巽柔顺，上艮知止。

整治积弊，既要顺人情，又要有止限，不可一往无度。

7. 振民育德

「振」，唤醒、振拔。唤醒沉陷在积弊习气里的民众，以德滋养，从根上化解蛊患。

四、逐爻深解，兼通老庄

初六｜干父之蛊，有子，考无咎，厉终吉

父辈留下的积弊，后辈承接而匡正整治。

有这样承继纠弊的后人，先祖可免于咎责。过程艰险，最终吉祥。

易： 治蛊的起点，子承父事——不是否定父辈全部功业，只清理其遗留的蠹坏。

最忌讳两种：全盘否定先祖，或是一味维护旧局。

老子： 敝而新成，在旧的根基之上更新，不毁其本。

庄子： 承接世务之弊，是因缘责任，但不可把纠弊当成自我的全部。

「考无咎」三个字，是这一爻最要紧的地方： 先人本有咎（留下了弊），而因为有个能干的儿子，这份咎被赦了。

——《易》不说「父无罪」，说的是「有子，考无咎」。 弊是真的，赦是因为有人接。 这句话的分量，所有承接旧局的人都该读一遍。

九二｜干母之蛊，不可贞

匡正母氏遗留的积弊，不可固守刚直、强持定见硬改。

易： 母之蛊，多偏在人情、私恩、情面层面的积习，不同于制度公事之弊。 人情盘根错节，刚性强治，容易伤亲和、激化矛盾——所以不可贞固硬行，宜委婉疏导。

老子： 柔弱胜刚强，人情之弊，不宜用猛法。

庄子： 人情缠缚的弊病，强行切割，伤害本根。

全卦六爻，只有九二说「不可贞」。

——这不是叫人不守正，是说：守正这件事，也有不该用的场合。 人情之弊的要害不在「对不对」，在「怎么切」；一刀下去，弊去人也去。

九三｜干父之蛊，小有悔，无大咎

整治父辈旧弊，用力偏猛，会生出小悔憾；但方向是匡正积蠹——没有大的过咎。

易： 有心治蛊，分寸难拿捏，容易操之过急，所以有小悔；本心在去蠹，不是破坏根基，所以不会酿成大祸。

老子： 治事贵知止，猛则偏，偏则生悔。

庄子： 有心去弊，已经落入「弊弊于事」，只是还没有离正道太远。

「小有悔，无大咎」——六个字，说的是一件很难说清的事： 做对了方向，但过了一点。

《易》不因为「过了一点」就判凶，也不因为「方向对」就没责任。 它给了一个极精确的刻度：小悔，无大咎。

——《易》对「热心过头的人」是最宽容的。

六四｜裕父之蛊，往见吝

对父辈遗留的积弊一味宽纵姑息、包容放过，不愿整治——长此以往，必有困吝。

易： 治蛊最大的惰性，就是「和稀泥」。因为念旧、顾情面，放任蠹坏持续蔓延。 随卦的悦、亲比的情，最容易生出这种姑息。

老子： 「为之于未有，治之于未乱」——积弊已经显现还姑息，隐患渐深。

庄子： 沉溺旧局的安逸情面，回避弊病，最后必被蠹坏所困。

六四是全卦唯一的「阴爻居阴位」——位置最正，判词最差。

它什么都没做错。它只是没做。 ——这就是《易》最冷的一处：有时候「无为」不是智慧，是姑息。

六五｜干父之蛊，用誉

匡正旧弊，获得称誉。

不是靠张扬功劳，是以德、以中道稳妥革新——众人自然信服赞美。

易： 治蛊的中道典范。纠弊而不刻薄，革新而不决裂，守住分寸，以德感召，所以得誉。

老子： 「光而不耀」「功成而不居」——只是顺节律除蠹。

庄子： 成事而不自矜，美誉只是附带的结果，不是追求的目标。

六五上承上九之刚——这一层要看清楚： 六五以柔居尊，治蛊靠的不是自己的威，是「用誉」，而它上面那个上九，正是全卦唯一「不事王侯」的人。

——一个能得誉的君，上面坐着一个不要名的人。 这个搭配，是蛊卦给治蛊者安排的最后一课。

上九｜不事王侯，高尚其事

不去承接王侯天下的事务、不去卷入朝堂层层纠缠的积弊网罗，守住自身高洁的本分。

易： 全卦的另一重抉择。 蛊是世间层层相连的积弊链条：有人入世干蛊、匡救时弊；也有人看透世事蠹坏循环，不入局，守自性之高。

这不是逃避，是另一种抉择。

老子： 功成身退，不持续纠缠于层层往复的世事纠治。

庄子： 核心对齐《逍遥游》「孰弊弊焉以天下为事」——不耗精神于无穷无尽的世事蛊患循环。

上九的《象》辞只有五个字，而它是全卦最高的评语：「不事王侯，志可则也。」

「志可则」——这个人的志，可以作为法则。

——《易》没有说「他不干活」，说的是「他的不干活，可以给人当准则」。 这是《易》对「退」最正面的一次表态：退不是消极，退是一种可法的志。

五、体系联动

随与蛊相邻，而两卦的卦变方向正好相反——这是全卷的骨架，也是全书最漂亮的一对：

  • 随《彖》：刚来而下柔——阳刚主动往下走。 所以「动而说（悦）」——上面的人肯下来，下面的人就高兴。
  • 蛊《彖》：刚上而柔下——阳刚往上走，柔爻给压到下面去。 所以「巽而止」——风被困在山下，出不来。

同一对刚柔，随是刚下来，蛊是刚上去。

——刚一下来，人心就跟着（随）；刚一上去，下面就开始长虫（蛊）。

这句话可以放到最朴素的说法里： 上位的人肯往下坐一点，大家就愿意跟；上位的人一直往上走，下面的人就只能在底下闷着——闷久了，就要坏。

「干父之蛊」三见，是《易》里同一句式最多的一处：

爻 原文 判词
初六 干父之蛊，有子，考无咎 厉终吉
九三 干父之蛊 小有悔，无大咎
六五 干父之蛊 用誉

同一个动作，三种分寸，三种结果。

  • 初六位最卑，刚接手，所以「厉」——先难后吉。
  • 九三居下卦之上，用力最猛，所以「小有悔」——方向对，过了一点。
  • 六五居尊位，以柔用德，所以「用誉」——不靠力气，靠人心。

——同是治旧弊，位置不同，分寸就不同，结果也就不同。 这就是《易》的「位」：它从不问「这事该不该做」，只问「你现在站在哪儿做」。

「蛊」与「大有」，判词都只有「元亨」而无「利贞」：

  • 大有：元亨。（没有「利贞」）
  • 蛊：元亨。利涉大川。（也没有「利贞」）

两卦共享一个特点：关口都不在「守不守正」，在「动不动手」。 大有是「有了之后怎么处」，蛊是「弊了之后怎么治」。 ——守正这一关，这两卦早就过了；它们卡住的地方，都是「做不做」和「怎么做」。

《杂卦》给蛊的一字训，是全《易》对治蛊最简明的定义：「蛊则饬也。」

「饬」是整治、整肃。 ——蛊这个字读起来凶，其实《杂卦》一句话就说完了：它是「该整一整」的意思。

《序卦》给出的下一站：「有事而后可大，故受之以临。临者，大也。」

——随 → 蛊 → 临。 跟（随）→ 出事（蛊）→ 整治之后局面变大（临）。

这条链比上一卷那条更长： 豫（高兴）→ 随（跟着走）→ 蛊（出事）→ 临（整治而后大）。 四个字连起来，是一件事的完整起落：乐、从、弊、治。

与老庄：

  • 《易》之蛊：揭示「随顺久则生蠹」的闭环。 两条路径：入世干蛊、中道革弊；出世不事王侯、守高自全。 核心戒两条：姑息裕蛊、猛治伤本。 它给的是治蛊的「分寸」。
  • 老子：「敝则新」（二十二章）。 蛊就是「敝」，而敝本身就是新的契机——「故物或损之而益」。治敝的关键在知时、知止，不妄作。 他给的是蛊的「转机」。
  • 庄子：更深一层看见循环——世事的蛊，治了又生，无穷往复。 上九「高尚其事」，就是看破这套循环，不把一生心神耗在持续不断的除蠹事务里。 他给的是蛊的「出口」。

一句话：易问「怎么治」，老子问「什么时候治」，庄子问——你治得完吗？

六、合与和

蛊卦的「合」，有两个方向，两个都错，而且方向相反：

一种是姑息求合——碍于旧日情分、相随的情面，掩盖弊病，维持表面和悦。

另一种是激进求合——推翻一切旧制，强行改造，以强力清除积弊，求一个全新的格局。

一个不动，一个大动；一个怕伤人，一个不怕伤人。 ——两样都是强求之合。

而蛊卦给的路在中间，且极窄：

初六说「厉终吉」——要动手，但先难。
九二说「不可贞」——人情那一路，不能硬来。
九三说「小有悔，无大咎」——可以过一点，但不能大过。
六四说「往见吝」——不动就困。
六五说「用誉」——靠德，不靠力。
上九说「志可则」——也可以根本不下场。

——六个位置，六种分寸，没有一种是「标准答案」。 这就是治蛊的实况：它没有通法，只有分寸。

天道之和：郁积生蠹是时序之必然；知其蠹而顺节律整治。

预察于甲前，养护于甲后；能干则中道匡正，人情之弊委婉疏导；同时明白有「不入局」的选项。

革故而不绝本，更新而不妄扰，终而复始，顺天行循环——是和。

所以蛊的「和」，落在《象》那四个字上：振民育德。

——《易》没有把治蛊的技术放在最前面，把「振」和「育」放在最前面。

振是唤醒，育是养。 先把人从弊气里叫起来，再把德养回去。 ——所有的制度修补，都排在这两件事后面。

因为弊不在制度里，弊在人身上；人不振，制度改十遍也长虫。

七、常见误读

一、「蛊」是巫术、是蛊毒、是邪术。

《说文》本训是「腹中虫」——人体内的寄生虫；「皿虫为蛊」是《左传》的另一路说法。

两说都指向同一件事：病在里面，看不见，慢慢腐蚀。

《杂卦》一句话就把这个字说完了：「蛊则饬也」——它是「该整一整」的意思。

二、蛊卦讲的是邪恶、凶事。

《彖》说：「蛊，元亨，而天下治也。」

——「天下治」三个字是本卦的定盘星。 蛊之所以元亨，不是因为有弊，是因为能治弊。 把蛊读成凶卦，这一句就落不下去。

三、「干父之蛊」是推翻父辈、否定前人。

「干」训「正」——是匡正，不是推翻。

初六说得很清楚：不是否定父辈全部功业，只清理其遗留的蠹坏。 而「考无咎」三个字更明白：先人的咎是真的，赦是因为有人接。

四、「先甲三日，后甲三日」是择吉日、避凶日。

「甲」是天干之始，代表一个周期的开端。 先甲三日（辛壬癸）是上一周期的末端——预察；后甲三日（乙丙丁）是新周期的开头——守成。

《彖》说「终则有始，天行也」——治蛊的全部技术，就在这「终」与「始」之间的六天上。 不是算日子，是算火候。

五、「裕父之蛊」是宽厚、是仁。

是姑息养患。

六四是全卦唯一「阴爻居阴位」——位置最正，判词最差。 它什么都没做错，它只是没做。 ——有时候「无为」不是智慧，是姑息。

六、「不事王侯」是逃避、是消极避世。

上九的《象》辞只有五个字：「志可则也」——这个人的志，可以作为法则。

《易》没有说他「不干活」，说的是他的不干活「可以给人当准则」。 这是《易》对「退」最正面的一次表态。

七、随与蛊只是《序卦》串起来的两卦，没有结构关系。

两卦互为综卦，而卦变方向正好相反：随是「刚来而下柔」，蛊是「刚上而柔下」。

同一对刚柔，随是刚下来，蛊是刚上去。 ——刚一下来，人心就跟着；刚一上去，下面就开始长虫。

这是全书最漂亮的一对卦变对照，而它恰好落在相邻两卦上。

八、「干父之蛊」出现三次是重复。

三见而三判：厉终吉（初六）、小有悔无大咎（九三）、用誉（六五）。

同一个动作，位置不同，分寸不同，结果就不同。 ——《易》从不问「这事该不该做」，只问「你现在站在哪儿做」。

九、治蛊就是修制度、补漏洞。

《象》给的根本方是「振民育德」——振是唤醒，育是养。

先把人从弊气里叫起来，再把德养回去；所有的制度修补都排在这两件事后面。

因为弊不在制度里，弊在人身上；人不振，制度改十遍也长虫。

随顺日久，郁积生蛊；革蠹更新之后，以德临民，便是临卦。

下一卦临。

—— 润泽说易
