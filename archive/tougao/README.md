# 投来稿存档规则

本目录存《润泽说 道可道之易传》用户投来的卦稿**原始文本**，与主稿（校订定本）并行保存，供复核、对照、追溯校订留痕。

## 命名

`<卦序三位>-<卦名>-原稿.md`（卦序按通行本六十四卦次第，如 `042-益-原稿.md`）。

## 三条规矩

1. **一字不改。** 原稿的措辞、标点、异体、可疑处，一律原样保存，不做任何校订。校订发生在主稿，不发生在存档。
   - **执行留痕（2026-11-13 补记）**：040—061 为原文逐字存档。**062—063（小过、既济）落盘的是并入时的定稿本（含校订），与规矩一不符**，其原稿在本轮会话中已随上下文压缩不可回溯，**不凭记忆回填**，待用户重发时按本规则覆盖补正。**064（未济）已按用户原文逐字重录**（v1.49.1 补正）。
2. **收到即落盘。** 每次收到卦稿，第一步先写本目录，再动主稿。此前多次因先写草稿（`/tmp`）后并入，中间态丢失。
3. **不补造。** 没有收到过的卦稿、或会话/临时目录已不可回溯的，不凭记忆回填，宁缺不假。
