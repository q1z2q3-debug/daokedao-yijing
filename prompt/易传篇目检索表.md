## 一、上篇｜系辞上　—— 一套占书，怎么被说成一部道书

| 节 | 本节主眼 |
|---|---|
| 一、经文底本 | 十四章全文。三注：劳谦段脱文（「德言盛，礼言恭」＋「谦也者，致恭以存其位者也」）；「天一地二」错简之争；分章十四是朱熹读法 |
| 二、时代社会背景 | 战国中后期孔门后学传文。卜筮仍行而人只问结果；诸子各立道论。作《系辞》者做一件事：**把一部占书说成一部道书** |
| 三、关键字造字溯源 | 十字四层（字形／训释／用例／义理）：易、乾坤、象、极、阖辟、形上形下、赜、神、几、太和。两处核心：「易」甲骨不作蜥蜴形（蜥蜴是《说文》以义逆形）；「神」字源为祭祀而行用全作「不测」 |
| 四、逐段深解（择七枢纽） | ①天尊地卑→易简 ②吉凶悔吝→三极 ③一阴一阳→生生 ④易无思无为→寂感（主语是蓍卦不是心体）⑤大衍五十→虚一（五说并存）⑥太极生两仪（不是创世是分层）⑦书不尽言→立象尽意（五个「尽」对一个「忘」） |
| 五、体系联动 | 与下篇：上立体、下起用。与《庄子》：同时代同病理，处方相反（一个撤、一个建）。与乾坤两卦：「各正性命，保合大和」——重在「各」与「保」。与《天下》：一个不缝、一个重建 |
| 六、合与和 | **「保合太和」的「合」是「保合」＝护持不散，不是「强合」＝削平差异**；同一个字两个方向，护的是同一件：差异本身 |
| 七、常见误读 | ①天尊地卑＝等级论（原文讲态势与位次）②易＝蜥蜴③保合太和是《系辞》原文（实出《乾·彖》）④立象尽意＝得意忘言（方向相反）⑤大衍五十是算术题⑥太极是具体存在物 |

## 二、下篇｜系辞下　—— 一部讲吉凶的书，自己在正文里写着「不可为典要」

| 节 | 本节主眼 |
|---|---|
| 一、经文底本 | 十二章全文＋末段。四注：**「无祇悔」非「无祗悔」（祇，大也）**；「信」两处通「伸」（来者信也、以求信也）；罔罟／隤然／殊途三处通假；**「因贰」三说（阴阳之二／疑／变）并存** |
| 二、时代社会背景 | 与上篇同属战国中后期传文，但调子从「立」转「忧」。三件事：推八卦成文明史（十三件器物）、把「吉凶」改成「无咎」、把易改成「不可为典要」 |
| 三、关键字造字溯源 | 八字：**几**（从丝从戍，守其微）；**穷**（从穴从躬，穷是路堵不是人完）；**絪缊**（乱麻相缠，化生是「缠」不是「雾」）；**撰**（具也，非撰写）；**典要**（死规矩，易自禁之）；**时**（位与机合一）；**贰**（三说同根）；**信＝伸**（读错则整段废） |
| 四、逐段深解（择九枢纽） | ①八卦成列→贞夫一 ②天地大德曰生→理财正辞 ③观象制器十三件（**「盖」是推测之词**）④易者象也＋阳卦多阴（少者为贵）⑤憧憧往来→屈信相感（**收回去是为了伸出来**）⑥诸爻六则（**危者安其位者也**）＋知几＋颜子 ⑦**「作《易》者，其有忧患乎」单立**＋九卦 ⑧变动不居·不可为典要（**易的自我否定条款**）⑨三才／辞危／**其要无咎**／六辞 |
| 五、体系联动 | 与上篇：两个落点收在同一处（「存乎其人」／「道不虚行」）。与《庄子》：**必分的一条——《系辞》有「位」，庄子拆「位」**。与六十四卦：九卦是次第；「不可为典要」是戒律。与《老子》：反者道之动（返）vs 穷则变（换） |
| 六、合与和 | **求吉是「合」，求无咎是「和」**。三处反面：以定法为真理／硬撑不换路／非要好结果。**「保合」的「保」靠「惧」** |
| 七、常见误读 | ①忧患＝悲观 ②穷则变＝革命口号（原义是换法）③同归殊途＝乐观安慰 ④不可为典要＝随便 ⑤九卦都是吉卦（里面有《困》）⑥六辞＝相面术 |

## 三、附 录｜忧患九卦详释　—— 九个把手，不是九级台阶

| 节 | 本节主眼 |
|---|---|
| 一、这个附录为什么单立 | 九卦是全书落点；最易被读成占断（里面有《困》）；每卦都有一处「合」的反面。更正两处归属：**「知雄守雌」出《老子》二十八章、「生而不有」出五十一章，都不是庄子** |
| 二、三陈原文 | 一陈定性／二陈性情／三陈功用。次序本身有讲究：先名，再貌，最后才谈用 |
| 三、九卦逐条 | 每卦卦象／字源（分层）／三陈／合和／庄子对照。硬处：**履本义是「鞋」**；**益从水从皿，本义是「溢出」**；**「复小而辨于物」是「因小而辨」**；**「困」字形本象是「围」** |
| 四、九卦的结构 | **四对一权**：履谦（行守）／复恒（回住）／损益（空满）／困井（困通）＋巽单出。前八卦是体，第九卦是用。头尾都是「入」 |
| 五、一条总按 | **「《井》以辨义」在前，「《巽》以行权」在后，顺序不能倒**。排成必须走完的进度表，就是「合」 |

## 四、上 经｜乾 · 坤　—— 六十四卦的头两卦（详表）

| 节 | 本节主眼 |
|---|---|
| 乾·一、经文底本 | 卦辞、六爻、用九、彖、象、文言全文。四注：**文言「贤人在下位而无辅」脱「位」字**；「可与几也」的几放在九三；**「保合太和」第一次读到原文（在《彖》）**；用九是乾独有的总出口 |
| 乾·二、时代社会背景 | **文王演易困于羑里是旧说，非定论**；殷人天帝信仰→周人「天命随德转移」；**天行健的「健」不是「行」**；**老庄不是「稍后于周初」，晚了六七百年——不是继承，是回应** |
| 乾·三、核心字造字溯源 | 六字：**乾**（本字「倝」，从日，日出旗影上腾，非「从乙」）、**龙**（甲骨即兽形；「阳气屈伸」是用例层）、**元**（从一在兀上，本义人头→始）、**贞**（甲骨即「卜问」，本义不是「正」）、**亢**（本义人颈）、**首**（一身只有一个） |
| 乾·四、逐爻深解 | 初九（勿用是自己按住的）／九二（闲邪存诚，诚是守不是有）／九三（**最险之位**；**「修辞立其诚」是全部中国文章学起点**）／九四（**「或」是不轻信自己**）／九五（**正位不是顶点，中才是正**；要害在「不宰」）／上九（**「有悔」是会有不是必有**）／用九（**群龙无首＝各当其位**） |
| 乾·五、体系联动 | 与九卦：一表六对（潜—复、见—谦、惕—履恒、或—巽、飞—益、亢—困）。**与老庄三层说：乾健而能止、健而不首；老子给乾配刹车；庄子越过刹车** |
| 乾·六、合与和 | **「想做那个『首』」是所有合的原点**：首→标准→同形→亢→悔。**「自强不息」的「健」是不停，不是不止** |
| 乾·七、常见误读 | ①文王作卦辞 ②**「群龙无首」＝乱成一团（正相反）**③亢龙有悔＝盛极必衰的宿命 ④九五就是顶点 ⑤保合太和＝和稀泥 |
| 坤·一、经文底本 | 三注：**「阴疑于阳」的「疑」读作「拟」**；「安贞吉」标点两可；**「直方大」的「大」是量不是第三种德** |
| 坤·二、时代社会背景 | **两卦的忧患方向相反：乾怕「亢」，坤怕「不甘」**；后来六十二卦的凶咎大半归入这两类：亢，或者战 |
| 坤·三、核心字造字溯源 | 七字：**坤**（本作巛即川之顺形）、**牝**（为什么是马不是牛——马顺而能行）、**章**（乐竟为一章）、**括**（束也，扎紧不是撕破）、**黄**（土色居中）、**玄黄**（伤不是流血，是混色）、**永贞**（乾之贞是所问，坤之贞是所守） |
| 坤·四、逐爻深解 | 初六（**「由辩之不早辩也」**）／六二（敬义立而德不孤）／六三（**「弗敢成」不是不能成，是不敢算成自己的**）／六四（**六三时开、六四时闭**）／**六五（黄裳与乾九五成一对）**／上六（**称龙正是说它已不是自己；两败不是胜利**）／用六 |
| 坤·五、体系联动 | **九卦里没有乾也没有坤——乾坤是体、是总纲，九卦是用、是处境**。与乾卦对勘七栏（象／德／时／位／戒／用／病）。**「知雄守雌」最准的讲法是乾坤合一** |
| 坤·六、合与和 | **明着做主与等着做主，用的是同一副心**。**柔顺若只是「还没到时机」，它就还是合**（忍了二十年力量够了就翻脸，那二十年不是和，是合的潜伏期） |
| 坤·七、常见误读 | ①坤＝软弱依附 ②含章＝压抑才干 ③括囊＝永远闭嘴 ④龙战于野＝阴的胜利 ⑤地道无成＝叫人不作为 |
| 乾 坤 对 勘 | 两个「用」（放与守）／两个「正位」（都在五）／两个「病」（盈与穷）。**收在一句：保，是乾的事；守，是坤的事——两个都不做「首」，太和才在** |

## 八、怎么用这张表

1. **问某一卦**：先在第五、六节的速查表定位——卦体定象，卦辞定纲，卷眼定调，再看该卷七节。
2. **问某一爻**：卦卷内六爻为 `####`，每爻固定四段（原文与解／易／老子／庄子）＋一行《象》辞。
3. **问字源**：一律按四层（字形／训释／用例／义理）答；形声与会意未查清的，照实说「未查清」，不拿义理顶替字义。
4. **问「全书唯一／只此一见」类问题**：先查第七节凡例索引；不在索引里的，**不作断言**，须先通检（含《彖》《象》，不止爻辞）。
5. **问进度**：六十四卦已全，卦卷六十三（乾坤合一）；每卦一卷，七节同构。
